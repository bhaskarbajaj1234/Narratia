📚 Narratia

AI-powered content creation studio

Narratia is a full-stack web application built using React + Vite on the frontend and Node.js + Express on the backend. It enables users to generate and edit images, write or review articles, and create or refine resumes using AI-powered tools—all in one unified interface.

✨ Features
🎨 Image Generation & Editing

Create, edit, and enhance images using AI-driven generation tools.

✍️ Article & Content Writing

Draft articles, blog posts, essays, or any type of written content with AI assistance.

📄 Resume Writing & Review

Create new resumes, polish existing ones, and get AI-backed suggestions for improvement.

🔗 Full-Stack Architecture

A unified app with a React + Vite frontend and a Node/Express backend for smooth integration and fast performance.

🛠️ Getting Started
Prerequisites

Node.js v14+

npm or yarn

📥 Installation
Step 1: Clone the repository
git clone https://github.com/bhaskarbajaj1234/Narratia.git
cd Narratia

Step 2: Install dependencies
In root directory:
npm install

Optionally install inside subfolders:
cd client && npm install
cd ../server && npm install

🚀 Running Locally
Start the backend
cd server
npm start      # or node index.js

Start the frontend

Open another terminal:

cd client
npm run dev    # or your configured start script


Your application will be running (typically at):
👉 http://localhost:3000
