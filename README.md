Narratia — AI-powered content creation studio
A web application built with React + Vite on the frontend and Express/Node on the backend. Narratia helps users generate and edit images, as well as write and review articles and resumes using AI.

Features:
1. Image generation & editing — Create or modify images using AI-powered tools.
2. Article & content writing — Generate drafts for articles, blog posts, or other written content.
3. Resume writing & review — Generate and polish resumes, or get AI suggestions for improvement.
4. Unified full-stack setup — React + Vite frontend and Node/Express backend for seamless user experience.

Getting Started:

Prerequisites
Node.js (v14 or above recommended)
npm or yarn

Installation:
Step-1 Clone the repository:
git clone https://github.com/bhaskarbajaj1234/Narratia.git
cd Narratia

Step-2: Install dependencies for both server and client:
# in root  
npm install  
# optionally also install inside subfolders  
cd client && npm install  
cd ../server && npm install  

Running locally
Start backend:
cd server  
npm start   # or `node index.js`, depending on your entry file  

Start frontend (in another terminal):
cd client  
npm run dev   # or your configured start command  

Your app should now be accessible (e.g. at http://localhost:3000 — depending on your configuration).
